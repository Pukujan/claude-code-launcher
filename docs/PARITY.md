# Windows and Mac launchers, side by side

Both launchers start the same proxy from `shared/litellm/`, offer the same 20
models, seat them through the same `apply_inferhub_seat.py`, and hand Claude
Code the same environment. They differ mostly in how they ask questions and how
much they install for you.

Compared as of 2026-10-03 (updated for issue #11):
`windows/launch-claude-inferhub.ps1` (PC copy taken at SHA-256 `9bf23ea0…`, plus
the edits in `SOURCES.md`) and `mac/Launch Claude InferHub.command` with
`mac/setup.sh` and `mac/lib/nav.sh`. There is one Mac launcher now; the old
`macos/` shim was folded into `mac/`.

## Same on both

| Feature | Behaviour |
| --- | --- |
| Built-in model table | The same 20 rows, names, ids, eligible or gated tags and costs. `tests/test_top20_tables.py` and `tests/test_ire_fetch.py` fail if they drift from each other or from `shared/ire/defaults.json`. |
| IRE fetch | Both run `shared/ire/ire_fetch.py` at start-up (live from GitHub, else cache, else defaults), print an `IRE:` line, set `CCL_IRE_JSON`, and never stop on a failure. |
| Defaults | Main is DeepSeek V4.1 Flash (`cb/deepseek-v4.1-flash`). Advisor is OFF. |
| Seat aliases | `sonnet`, `main`, `claude-sonnet-5` and the `ih-*` main names go to the main seat. `opus`, `advisor`, `claude-opus-5-5`, `claude-fable-5*` and the `ih-*` advisor names go to the advisor seat. With the advisor OFF, they go to main. `haiku`, `claude-haiku-5`, `small-fast` and the `ih-*`/`inferhub-haiku` fast names go to the fast seat, `ali/qwen3.8-flash` by default. |
| Fallback chains | Generated by `merge_litellm_config.py` from `inferhub_fallbacks.yaml`. |
| Proxy address | `http://127.0.0.1:4000`, bound to 127.0.0.1 only. |
| Proxy key | None by default. A `LITELLM_MASTER_KEY` set in an env file is passed through. With no key, `runtime.yaml` has no `master_key`, and the proxy process (only) gets `LITELLM_DANGEROUSLY_PERMIT_WEAK_OR_UNSET_MASTER_KEY=true`, which LiteLLM 1.104+ needs to start keyless. |
| Key given to Claude Code | `ANTHROPIC_API_KEY` is the master key if set, otherwise `local`. `ANTHROPIC_AUTH_TOKEN` is never set. |
| Claude environment | Clears the same list plus anything matching `ANTHROPIC_*`, `CLAUDE_CODE_*`, `CKFF_*`, `ckff_*`. Then sets `ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL`, `ANTHROPIC_MODEL=sonnet`, `ANTHROPIC_SMALL_FAST_MODEL=small-fast`. Experimental betas stay on. |
| Claude command | `claude --model sonnet --permission-mode bypassPermissions` in the chosen folder. |
| `~/.claude/settings.json` | Only touched if it exists. Same `modelPicker` options, `model: sonnet`, `advisorModel: opus`. |
| Health check | `/health/liveliness`, then `/readiness`, then `/liveness`. Waits up to 300 s and gives up early if startup fails. |
| A healthy proxy already running | Reused as-is. |
| Something else on the port | Left alone. The launcher stops with an error. |
| Requirements | `shared/litellm/requirements.txt` plus `requirements-overrides.txt`. |
| Top 20 deployments | Written by `sync_inferhub_top20.py`. With no IRE CSV, from `shared/litellm/config/top20-builtin.csv`. |
| Logs | `shared/litellm/logs/litellm.out.log`, `litellm.err.log`, `litellm.pid`. |

## Different

| Feature | Windows | Mac | Why |
| --- | --- | --- | --- |
| Entry point | `launch-claude-inferhub.cmd`, which opens the `.ps1` in a window that stays open | `Launch Claude InferHub.command` | Platform double-click conventions |
| Order | Main, advisor, folder, then seat and proxy | Proxy, then folder, main, advisor, then seat | The Mac seats into the running proxy with a hot reload. Windows seats before starting the proxy and again after. |
| Folder list | `D:\development` and its subfolders, then `C:\work` and its subfolders | `~/work` and its subfolders, then recent folders. `b` browses the filesystem in the terminal, `q` offers quick picks, `t` takes a typed path, `n` makes a new folder. No Finder dialog. | Different disk layouts. The terminal navigation came from the old `macos/` shim. |
| Picker keys | Arrow keys, Page Up/Down, Home, End | Model and folder lists: type a number, Return for the default. The folder browser (`b`) uses arrow keys. | The numbered lists also work from a pipe, which the dry run relies on. The arrow-key browser reads whole escape sequences and is tested under bash 3.2. |
| Model table at run time | The built-in `$Models` table. The IRE answer is only passed on as `CCL_IRE_JSON`. | The IRE Top 20 from `ire_fetch.py` when it answers, else the built-in `MODELS` | Windows hasn't been switched to the live table yet |
| IRE frontier list | Tab in the main and advisor pickers switches to it (from the `frontier` key of `CCL_IRE_JSON`) | `f` at the main and advisor prompts (same key, through `ladder_cli.py primary`) | Same data, different keys. A `cx/` seat from it runs in Responses mode on both. |
| Skip a picker | Not available | `CLAUDE_IH_PROJECT`, `CLAUDE_IH_MAIN`, `CLAUDE_IH_ADVISOR` (or the old `ACS_*` names), or `claude-acs <folder>` | Used by the Mac dry run |
| Installer | None. Clone and double-click. | `mac/setup.sh`: same first-run installs, then a `claude-acs` command in `~/.local/bin`; `--check` and `--uninstall` | From the old `macos/` shim |
| First-run installs | None. Python (or uv) and Claude Code must already be there; `start-litellm.ps1` makes the venv with uv, or with `python -m venv` and pip when uv is missing. | uv, Python 3.12, the venv, and Claude Code if missing | The Mac is meant to work from a fresh machine |
| Override install | `uv pip install --override`; without uv, a second `pip install` of the override pins (pip warns about the conflict) | `uv pip install --override` | Same tool on both when uv is installed |
| Env files | CKFF keys from `configs\.env` on the Desktop (Desktop known folder, then `%USERPROFILE%\Desktop`, then `%OneDrive%\Desktop`). InferHub keys from the first that exists of the IRE `.env`, the repo `.env`, `~\.config\inferhub\.env`. Both paths go to the start script. | Repo `.env`, then `~/.config/inferhub/.env`, then the shell environment | Where the keys already live on each machine |
| InferHub key prompt | None. The key must already be in a file. | Asked once with hidden input, saved with mode 600 | First-run convenience on the Mac |
| CKFF keys | Required by `start-litellm.ps1` | Optional, passed through if present | The PC also serves the CKFF model groups |
| IRE CSV lookup | `-Top20Csv`, then `config\top20.csv`, then the built-in CSV | `INFERHUB_TOP20_CSV`, then `config/top20.csv`, then `~/.config/inferhub/research_model_top20_recommendations.csv`, then the built-in CSV | The Mac keeps the ACS lookup for a downloaded IRE file |
| Stopping the proxy | `windows\litellm\stop-litellm.ps1` stops the PID in `litellm.pid`, and only if it is this repo's venv LiteLLM | `mac/stop-litellm.sh`, same rule | Same |
| After Claude exits | Prints the exit code and waits for a key | `exec claude`; the Terminal window shows the process ended | Kept from each source |
| Launcher log | Console only | `~/Library/Logs/claude-inferhub/launcher.log` | Kept from each source |
